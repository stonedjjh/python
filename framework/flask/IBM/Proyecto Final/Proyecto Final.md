# Proyecto Final - Descripción General y Criterios de Revisión

## Descripción del Proyecto

Para este proyecto final, asumirás el rol de un ingeniero de software que necesita desarrollar una aplicación web basada en IA. Analizarás el escenario y realizarás las siguientes tareas:

- **Tarea 1:** Clonar el repositorio del proyecto
- **Tarea 2:** Crear una aplicación de detección de emociones utilizando la biblioteca NLP de Watson
- **Tarea 3:** Formatear la salida de la aplicación
- **Tarea 4:** Empaquetar la aplicación
- **Tarea 5:** Ejecutar pruebas unitarias en tu aplicación
- **Tarea 6:** Despliegue web de la aplicación utilizando Flask
- **Tarea 7:** Incorporar manejo de errores
- **Tarea 8:** Ejecutar análisis de código estático

## Criterios de Evaluación – 16 Puntos

Puedes enviar los entregables de tu proyecto de una de las siguientes maneras:

- **Opción 1: Envío y Evaluación Calificada por IA**

Cuando elijas la Opción 1, serás redirigido a una herramienta de IA donde podrás subir tus entregables, que pueden incluir URLs, salidas de terminal, fragmentos de código o capturas de pantalla. Luego recibirás una calificación generada por IA que se reflejará automáticamente en tu página de progreso.

- **Opción 2: Envío y Evaluación Calificada por Pares**

Cuando elijas la Opción 2, subirás tus entregables—como URLs, salidas de terminal, fragmentos de código o capturas de pantalla—en la sección Mi Entrega. Tu entrega será revisada ya sea por tus compañeros o por el evaluador de IA.

[!TIP]
> Recomendamos usar la Opción 1 para una calificación más rápida. Sin embargo, si enfrentas problemas o no puedes acceder, puedes usar la Opción 2 en su lugar.
>
> Si encuentras algún problema de calificación, por favor contacta al Equipo del Curso a través de los Foros de Discusión.
