# Visión General del Proyecto de Práctica

En el proyecto práctico, se te presentarán bibliotecas de IA de Watson que se pueden incrustar. Luego, crearás una aplicación web integrada con las bibliotecas de IA de Watson para realizar un análisis de sentimientos sobre el texto proporcionado. Después de desarrollar la aplicación, desplegarás la mencionada aplicación en la web utilizando el framework Flask. Todas las actividades que te llevarán a desplegar aplicaciones web funcionales basadas en IA se desglosan en tareas como se detalla a continuación:

Tarea 1: Clonar el repositorio del proyecto
Tarea 2: Crear una aplicación de análisis de sentimientos utilizando la biblioteca NLP de Watson
Tarea 3: Formatear la salida de la aplicación
Tarea 4: Empaquetar la aplicación
Tarea 5: Ejecutar pruebas unitarias en tu aplicación
Tarea 6: Desplegar como aplicación web utilizando Flask
Tarea 7: Incorporar manejo de errores
Tarea 8: Ejecutar análisis de código estático
Se te proporcionará orientación en forma de instrucciones, capturas de pantalla y código para ayudarte a completar el proyecto. No habrá puntuación para este proyecto. Sin embargo, se recomienda encarecidamente que completes este proyecto antes de proceder al proyecto final.
